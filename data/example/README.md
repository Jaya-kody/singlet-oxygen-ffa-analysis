# Example data (synthetic)

Every file in this folder was generated by `scripts/make_example_data.py`.
The values are invented for demonstration and are **not** experimental data.

| File | Contents |
|---|---|
| `samples.csv` | sample IDs, dish type, replicate number |
| `ffa_decay/<sample>_<light>.csv` | FFA peak area vs time: `time_h, time_s, area, ln(FFAt/FFA0)` |
| `ffa_decay/<sample>_<light>_background.csv` | matching background-air control |
| `ffa_decay/REF_<light>.csv` | reference sensitizer run for each light |
| `absorbance.csv` | UV/Vis absorbance (1 cm) for each sample and the reference |
| `irradiance.csv` | spectral irradiance of each light source, W m⁻² nm⁻¹ |
